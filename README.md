# Kaela (BC) — unduh

**Link unduh (selalu versi terbaru):**
https://github.com/MrOlzGaming/kaela-bc-unduh/releases/latest/download/KaelaBC-Installer.zip

Cara pasang:
1. Unduh zip di atas → klik kanan → Extract All.
2. Klik 2x `INSTALL.bat`.
3. Ikuti panduan di layar (sekali saja: pasang ekstensi di Chrome).
4. Tiap main: klik 2x ikon Desktop **Kaela (BC)**.

Update: unduh lagi dari link yang sama, jalankan `INSTALL.bat` lagi.
